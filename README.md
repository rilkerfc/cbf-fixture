# cbf-fixture

Static test pages for TwoCents.

- `many-controls/`: a TwoCents test fixture with 35 visible controls (20 class buttons, 8 checkboxes, 4 same-page links, 1 text field, 1 select, 1 Sign up button) for aarpinnovationstudio/twocents#438.
- `late-hop/`: a TwoCents test fixture for aarpinnovationstudio/twocents#543 with three buttons: one sends the page to another origin 1000 ms after the click (a late hop), one does so at once (an early hop), and one moves to a same-site page 1000 ms after the click (the control).
